# RidePrism

[English](README.md) · **简体中文**

<img src="logo.svg" width="72" height="72" alt="RidePrism logo">

RidePrism 是一款面向户外骑行的 FIT 查看与分享工具，活动数据在浏览器中离线处理，不会上传到服务器。无需注册，也没有统计或追踪服务；你选择的 FIT 文件和背景图片不会因使用网站而被上传。

从一次骑行的数据回顾，到多段记录的合并，再到路线分享图的制作，都可以在浏览器中完成。支持中文与英文，以及浅色、深色和跟随系统的界面主题。

## 功能

- **回顾骑行**：查看距离、时长、均速、心率、功率、踏频、爬升、消耗热量和圈段，了解码表与传感器信息。通过交互曲线查看各时刻的数值，按需略过暂停或压缩长采样间隔。
- **查看路线**：在轨迹网格、本地底图或在线地图上查看骑行路线，以颜色呈现速度变化，按需显示每公里、速度与海拔极值标记，支持 WGS-84 与 GCJ-02 坐标修正。
- **合并记录**：加载多个 FIT，按时间拼接活动，导出合并 FIT 或逐点 CSV。
- **制作分享图**：组合路线与活动数据，选择配色、画幅和背景，添加标题与署名，导出高清 PNG。支持平面路线和基于海拔的三维路线，也可使用自己的照片或地图作为背景。

没有实测功率时，概览可根据速度与海拔估计骑行平均功率，并支持调整体重与车辆参数。估计采用无风基线，仅供参考，不能替代功率计；风、跟骑和数据质量都可能显著影响结果。

## 使用与部署

打开网站，选择或拖入 FIT 文件即可查看活动。需要制作图片时，点击“制作分享图”。

项目可直接部署到静态站点，无需构建或后端。本地使用时，通过 HTTP 服务打开即可。

翻译维护与新增语言见 [语言说明](language/README.md)。

## 在线底图

在线底图使用 OpenStreetMap，仅在你主动选择后加载。活动文件不会上传，但瓦片请求会向地图服务透露所查看的大致区域、IP 和网页来源。使用轨迹网格或本地底图无需在线地图请求。

本地底图支持 Web Mercator / XYZ 瓦片。在线底图保留版权署名，使用需遵循 [OpenStreetMap 瓦片使用政策](https://operations.osmfoundation.org/policies/tiles/)。

## 使用范围

- 支持常见 FIT 活动字段，厂商专用字段与暂停信息可能无法完整识别。长采样间隔不一定代表暂停。
- 合并导出保留常见活动数据，不保留设备信息和开发者自定义字段；时间重叠的记录不会自动去重。坐标修正与曲线时间压缩仅影响显示，第三方平台兼容性仍需验证。
- 三维路线展示记录中的海拔起伏，不生成真实山体地形。
- 单文件上限为 64 MB，已加载文件总计上限为 128 MB。
